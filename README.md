## What Is Keygen Music?

Keygen music (also called **bytebeat** or **demoscene synthesis**) is a technique from the cracking/demoscene subculture where entire musical pieces are generated by a single mathematical expression operating on a time variable `t`. The challenge: produce complex, recognizable music from the absolute minimum amount of code.

The most extreme form — the **one-liner** — fits an entire song into a single terminal command:

```bash
# Fate motif in one line (pipe to aplay):
python3 -c "
import sys
[sys.stdout.buffer.write(bytes([(
    (t>>10&1)*((t*[196,196,196,156,175,175,175,147][t>>11&7]>>8)&255)
)])) for t in range(1<<18)]
" | aplay -r8000 -c1 -f U8
```

**Breakdown of the one-liner:**
| Expression | Meaning |
|---|---|
| `t>>10 & 1` | Square wave gate — note on/off rhythm |
| `t>>11 & 7` | Selects 1 of 8 pitches (fate motif sequence) |
| `[196,196,196,156,175,175,175,147]` | G4,G4,G4,Eb4,F4,F4,F4,D4 — *da da da DAA* |
| `t * freq >> 8` | Integer oscillator — the bytebeat core |

## Full Synthesis Engine (`fate.py`)

The main program goes far beyond the one-liner, implementing a complete software synthesizer:

### Waveform Generators
| Function | Waveform | Character |
|---|---|---|
| `sine()` | Pure sine | Smooth, fundamental |
| `square()` | PWM square | Classic keygen buzz |
| `sawtooth()` | Sawtooth | Aggressive, rich harmonics |
| `triangle()` | Triangle | Warm, flute-like |
| `organ()` | Additive (7 harmonics) | Hammond organ |
| `strings()` | Detuned sawtooth pair | Lush string ensemble |
| `brass()` | Square + odd harmonics | Trumpet / French horn |
| `bass()` | Sine + 2nd harmonic | Deep sub-bass |
| `timpani()` | Inharmonic decay | Orchestral percussion |

### Signal Processing Chain
```
Score Data → Note Events → Waveform Generator → ADSR Envelope
    → Voice Buffer → Mix (4 voices) → Schroeder Reverb
    → Peak Normalize → Soft-Knee Limiter → 16-bit PCM → WAV
```

### ADSR Envelope
```
Amplitude
  1.0 ┤    ╭─╮
      │   ╱   ╲_________
      │  ╱               ╲
  0.0 ┼─╱─────────────────╲──▶ time
      Attack Decay Sustain Release
```

### Schroeder Reverb
Four parallel comb filters feeding two series allpass filters — the classic digital reverb algorithm from Manfred Schroeder (1962), used in everything from early synthesizers to modern DAWs.

### Score Encoding
The symphony is encoded as a list of `(pitch, duration, velocity, instrument)` tuples:
```python
FATE_MOTIF = [
    (G4,  0.25, 1.0, 'str'),   # da
    (G4,  0.25, 1.0, 'str'),   # da
    (G4,  0.25, 1.0, 'str'),   # da
    (Eb4, 2.0,  1.0, 'str'),   # DAAA
    ...
]
```

## Usage

```bash
# Requirements: Python 3.6+ standard library only
python3 fate.py

# Output: fate_symphony.wav
aplay fate_symphony.wav          # Linux
ffplay fate_symphony.wav         # Cross-platform
```
